# CloudReel Studio – first-time user screen

Empty state of the Studio page for a brand-new user: Schedule, Webinar and Live tabs, with Record marked "Coming soon". Mobile-first, React + Tailwind CSS v4 + Vite.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # output in dist/
```

Every push to `main` deploys to GitHub Pages via `.github/workflows/deploy.yml`.
